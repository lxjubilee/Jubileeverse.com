IMAGE GENERATION SYSTEM — DEFAULT (Claude + Leonardo Phoenix):
For all other categories, the system uses the two-stage prompt pipeline implemented in lib/jubilee-inspire-persona.js. In Stage 1 (_analyzeArticleForVisuals), the system uses claude-sonnet-4-5-20250929 with a maximum token limit of 900. This stage performs structured analysis of the article and returns a JSON object containing nine key dimensions: sentiment (emotional tone), dominant_metaphors (primary visual metaphors), thesis (theological core), climactic_moment (peak narrative beat), human_action (what the primary subject is doing), environment (physical setting), era_tone (time-period atmosphere), and two new fields — biblical_scene (detected biblical narrative) and biblical_character / biblical_period (associated period metadata).

In Stage 2 (buildImagePromptFromArticle), the system consumes the JSON output from Stage 1 and constructs a cinematic Leonardo Phoenix prompt. When the biblical_scene field is detected, the system activates a PRIORITY MODE. In this mode, the prompt injects period-accurate constraints, including linen robes and sandals, mud-brick architecture, oil lamps, Judean hill terrain, Jerusalem stone structures, and Mediterranean skin tones.
